* Overview

This tutorial installs NixOS on a OnePlus 6 (enchilada) with Mobile NixOS. You build a minimal base image on your desktop (the =local.nix= file, with fixes so it builds on x86 machines), flash it to the phone, and then rebuild on the phone itself with the full =configuration.nix= and the flake workflow you know from regular NixOS.

Video tutorial: https://youtu.be/yxfDNqZ9WTM

The base video still applies. Since then, this repository has moved from upstream Mobile NixOS to a fork, and the old =4g-testing= branch is folded into this tutorial.

** Why a fork of Mobile NixOS

Upstream Mobile NixOS still ships the SDM845 (Snapdragon 845) kernel at Linux 6.4, and its kernel build doesn't install kernel modules for cross-compiled builds. The Qualcomm modem stack (QRTR, QMI, RMNET, IPA) is built entirely from modules, so upstream never brings the modem up.

The fork at [[https://github.com/mwlaboratories/mobile-nixos/tree/main][mwlaboratories/mobile-nixos]] fixes that:

- *Newer kernel*: Linux 7.4 (release candidate) from the =sdm845-linus= branches of the [[https://codeberg.org/sdm845/linux][sdm845 kernel tree on Codeberg]], built from =defconfig= plus an =sdm845.config= fragment instead of a 7,500-line static config. It adds USB-C role switching and OTG power; the GPU, display and video clock controllers are built in, because as modules they load too late and the screen stays black.
- *Modules that actually load*: =isModular = true=, a =modDirVersion= that matches the kernel's release string, zstd for module compression, and an explicit =depmod= after install (when you cross-build on x86_64, =make modules_install= runs the host's =depmod=, which silently produces no =modules.dep=).
- *Smaller fixes*: Android sparse images for the SDM845 bootloader, more robust removal of =modem.mbn= from the initrd, and kernel builder updates for the newer kernel.

* What works

Measured on 2026-11-19 with NixOS 26.11 (nixos-unstable) and kernel =7.4.0-rc3=:

| Feature               | Status                                                              |
|-----------------------+---------------------------------------------------------------------|
| Display + GPU         | Works (1080×2280, Adreno 630)                                       |
| WiFi                  | Works                                                               |
| SSH / serial over USB | Works (see [[*Access over USB-C][Access over USB-C]])           |
| USB-C role switching  | Works: the phone picks device/host and power role by itself         |
| USB OTG power         | Regulator present; not yet tested with a device plugged in          |
| Cameras               | Capture works: rear 30 fps / 30 fps, front about 11.5 fps           |
| Speaker               | Works with PulseAudio ("Speakers Output")                           |
| Microphone / earpiece | Not yet tested                                                      |
| Modem                 | Starts at boot and is detected; 4G worked in earlier tests with a SIM |
| Calls / SMS           | Not retested on this release (needs a SIM)                          |
| Bluetooth             | Works: stable address, scanning finds nearby devices                |
| Sensors               | Light, compass, proximity and accelerometer report values           |
| Screen rotation       | Accelerometer works; the rotation direction is not yet checked      |
| Waydroid              | Won't work: Linux 7.4 dropped the C binder (needs the Rust binder)  |
| Suspend               | Disabled on purpose: the modem doesn't survive resume               |

* Clone This Repository

#+begin_src sh
git clone https://github.com/mwlaboratories/phoneputer.git
cd phoneputer
#+end_src

* Build Flashable Images

Build the base images from the Mobile NixOS fork. It ends up in a =mobile-nixos= folder under the project directory, and you only need it once, for this first install:

#+begin_src sh
git clone https://github.com/mwlaboratories/mobile-nixos.git
cd mobile-nixos
cp ../local.nix .
nix-build --argstr device oneplus-enchilada -A outputs.android-fastboot-images
#+end_src

Before building, put your WiFi name and password in =local.nix=, so the phone comes up on your network and you can SSH in. Your x86_64 machine needs =boot.binfmt.emulatedSystems = [ "aarch64-linux" ];= to build for the phone. The kernel compiles from source, so the first build takes a while.

* Prepare the Phone

** Update OxygenOS
1. Update OxygenOS to the latest official version
2. Remove all Google accounts to avoid FRP (Factory Reset Protection) blocks

** Enable Developer Options
1. Go to Settings → About Phone
2. Tap "Build Number" 7 times
3. Go back to Settings → Developer Options
4. Enable "USB Debugging"
5. Enable "OEM Unlocking"

** Unlock the Bootloader

Open a shell with Android tools:

#+begin_src sh
nix-shell -p android-tools
#+end_src

Check the device connection:

#+begin_src sh
adb devices
#+end_src

Reboot to the bootloader:

#+begin_src sh
adb -d reboot bootloader
#+end_src

Unlock the bootloader (this erases all data!):

#+begin_src sh
fastboot oem unlock
#+end_src

⚠️ *Warning*: Unlocking the bootloader erases all data on your device!

** Copy Partitions (A/B Safety Trick)

The inactive slot can be empty or hold much older firmware than the active slot, which leads to various problems, up to a hard brick. Copying the active slot to the inactive slot prevents all of that.

To do this, sideload the copy-partitions-20220613-signed.zip package:

1. On the device, select "Apply Update", then "Apply from ADB" to begin sideload
2. On the host machine, download and sideload the package:

#+begin_src sh
wget https://mirrorbits.lineageos.org/tools/copy-partitions-20220613-signed.zip
adb -d sideload copy-partitions-20220613-signed.zip
#+end_src

Now reboot to recovery by tapping "Advanced", then "Reboot to recovery".

** Prepare for Mainline

This assumes the phone will only run SDM845 mainline images. Erase the dtbo partitions for both slots:

#+begin_src sh
fastboot erase dtbo_a
#+end_src

#+begin_src sh
fastboot erase dtbo_b
#+end_src

* Flash Images to Device

Flash the critical partitions:

#+begin_src sh
./result/flash-critical.sh
#+end_src

Flash the system image:

#+begin_src sh
fastboot flash userdata result/system.img
#+end_src

⚠️ *Note*: If the phone isn't recognized, try connecting it /after/ booting into fastboot mode.

* First Boot and Configuration

** SSH into the Phone

The base image from =local.nix= enables SSH and WiFi. Find the phone's IP in your router, then connect (password: =nixtheplanet=):

#+begin_src sh
ssh root@<phone-ip>
#+end_src

** Rebuild with the Flake Configuration

From here on you work like on any NixOS flake install. Adjust =configuration.nix= to your liking, but build the included one first. It boots you into GNOME.

The fastest way is to build on your desktop and push the result to the phone:

#+begin_src sh
nixos-rebuild switch --flake .#phoneputer \
  --target-host root@<phone-ip> --build-host localhost
#+end_src

Or clone the repository on the phone and build there (slow: the phone compiles the kernel itself):

#+begin_src sh
git clone https://github.com/mwlaboratories/phoneputer.git
cd phoneputer
nixos-rebuild switch --flake .#phoneputer
#+end_src

After this rebuild the phone uses NetworkManager instead of the base image's WiFi setup. Connect to WiFi again in GNOME Settings → Wi-Fi. Then flash the kernel that matches this configuration, as described next.

* Updating the Kernel

=nixos-rebuild switch= updates everything /except/ the kernel. The kernel and initrd live in the =boot= partition, which the phone's bootloader starts directly. The boot image then starts the newest system generation. So whenever the flake's kernel changes (including the first rebuild above), build and flash a new boot image, so the kernel matches the modules in the system.

Build the boot image on your desktop:

#+begin_src sh
nix build .#nixosConfigurations.phoneputer.config.mobile.outputs.android.android-bootimg -o boot.img
#+end_src

Put the phone into fastboot mode over SSH (or power it off and hold Volume Up + Power):

#+begin_src sh
ssh root@<phone-ip> reboot bootloader
#+end_src

Try the new image /without/ flashing it first. =fastboot boot= starts it once; the next reboot uses the old kernel again:

#+begin_src sh
nix-shell -p android-tools
fastboot devices
fastboot boot boot.img
#+end_src

If everything works, flash it to the active slot. =fastboot getvar current-slot= shows which slot that is:

#+begin_src sh
ssh root@<phone-ip> reboot bootloader
fastboot getvar current-slot
fastboot flash boot_a boot.img   # use boot_b if the current slot is b
fastboot reboot
#+end_src

Keep a backup of the old boot partition before you overwrite it. On the phone, =dd if=/dev/disk/by-partlabel/boot_a of=/root/boot_a.img= (pick the active slot) gives you an image to flash back if the new kernel doesn't boot.

* Access over USB-C

Mobile NixOS only sets up a USB gadget during early boot, so a booted phone shows nothing over USB. =usb-gadget.nix= fixes that: after boot the phone presents a network interface and a serial console over the cable.

With the phone plugged in, your PC gets an address by DHCP and you can SSH in without WiFi:

#+begin_src sh
ssh root@172.16.42.1
#+end_src

The serial console shows up on the PC as =/dev/ttyACM0= (the number can differ):

#+begin_src sh
screen /dev/ttyACM0 115200
#+end_src

This is also what makes fastboot work remotely: =reboot bootloader= over SSH, and the phone appears in =fastboot devices= on the same cable.

* 4G / LTE

Insert a SIM card and reboot. ModemManager brings up the modem, and mobile data appears in GNOME Settings → Network. To check the modem from a shell:

#+begin_src sh
mmcli -L
mmcli -m 0
#+end_src

Without a SIM, =mmcli -m 0= reports state =failed= with reason =sim-missing=. That is expected.

* What's Next?

After the rebuild, your OnePlus 6 has:
- GNOME (with bloat removed)
- SSH over WiFi and over the USB-C cable
- The modem stack for 4G
- Full declarative NixOS configuration

You can now:
- Customise =configuration.nix= further
- Add more packages or services
- Rebuild any time with =nixos-rebuild switch --flake .#phoneputer=
- Use the device as a full Linux development environment
