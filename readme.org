* Overview

This tutorial puts NixOS with GNOME on a OnePlus 6 (codename /enchilada/). You build everything on your PC with one command, flash it once, and the phone boots straight into GNOME. After that you change the phone like any NixOS machine: edit its configuration and rebuild.

Video tutorial: https://youtu.be/yxfDNqZ9WTM (it shows an older two-stage install; the phone preparation is the same)

All OnePlus 6 hardware support (kernel, firmware, modem, Bluetooth, sensors, SSH over the USB-C cable) lives in a [[https://github.com/mwlaboratories/mobile-nixos][fork of Mobile NixOS]]. This repository holds the rest: GNOME made for a phone, the Stylix colours, a user and your apps (Home Manager).

** What you need

- A *OnePlus 6* (A6000/A6003). Not the OnePlus 6T: that is a different device (/fajita/).
- A USB-C cable that carries data.
- A Linux PC (x86_64) with [[https://nixos.org/download/][Nix]], flakes enabled, and the ability to run aarch64 programs:
  - On NixOS: =boot.binfmt.emulatedSystems = [ "aarch64-linux" ];= in your configuration, then rebuild.
  - On other distributions: install QEMU user emulation with binfmt support (e.g. =qemu-user-static= / =qemu-user-binfmt=) and add =extra-platforms = aarch64-linux= to =/etc/nix/nix.conf=.
- About 30 GB of free disk space and an hour, most of it waiting for downloads.

⚠️ Installing erases everything on the phone.

Measured on 2026-11-20 with NixOS 26.11 (nixos-unstable) and kernel 7.4.0-rc3:

* Step 1: Build the Images (on your PC)

#+begin_src sh
nix build github:mwlaboratories/phoneputer#images
#+end_src

This builds the kernel natively on your PC (a few minutes), downloads the rest of the system from the NixOS binary cache, builds the one package this configuration changes (GNOME Shell, for the colours on the login screen; a few minutes through emulation), and leaves everything you need to flash in =./result/=.

Want to change something first, like the user name or the packages? Clone the repository, edit =hosts/phoneputer/configuration.nix= (or =home.nix= next to it for your apps), and build from there:

#+begin_src sh
git clone https://github.com/mwlaboratories/phoneputer.git
cd phoneputer
nix build .#images
#+end_src

Let it build while you prepare the phone.

* Step 2: Prepare the Phone

These steps are the same for every custom OS on the OnePlus 6.

** Update OxygenOS and remove Google accounts

1. Update OxygenOS to the latest official version.
2. Remove all Google accounts, so Factory Reset Protection can't block you later.

** Enable developer options

1. Settings → About Phone → tap "Build Number" 7 times.
2. Settings → Developer Options: enable "USB Debugging" and "OEM Unlocking".

** Unlock the bootloader

Get the Android tools on your PC:

#+begin_src sh
nix shell nixpkgs#android-tools
#+end_src

Connect the phone, allow USB debugging on its screen, and reboot it into the bootloader:

#+begin_src sh
adb devices
adb reboot bootloader
#+end_src

Unlock (this erases the phone) and confirm on the phone's screen:

#+begin_src sh
fastboot oem unlock
#+end_src

** Make both A/B slots safe

The phone has two copies ("slots") of its firmware. The inactive one can be empty or much older, which can brick the phone later. Copy the active slot over it once. The package comes from LineageOS and needs the LineageOS recovery to install it. Booting that recovery works as in the [[https://wiki.lineageos.org/devices/enchilada/install/][LineageOS install guide for the OnePlus 6]].

1. Download the recovery image for /enchilada/ from the [[https://download.lineageos.org/devices/enchilada/builds][LineageOS downloads]] and flash it to the boot partition, from the bootloader. The Mobile NixOS flash in step 3 overwrites it again:

#+begin_src sh
fastboot flash boot <recovery_filename>.img
#+end_src

2. With the volume keys, choose "Recovery mode" on the bootloader screen and press Power. In the recovery, choose "Apply Update", then "Apply from ADB".
3. On the PC:

#+begin_src sh
wget https://mirrorbits.lineageos.org/tools/copy-partitions-20220613-signed.zip
adb sideload copy-partitions-20220613-signed.zip
#+end_src

4. Tap "Advanced" → "Reboot to bootloader".

** Erase the Android device tree overlays

The mainline kernel needs these gone, on both slots:

#+begin_src sh
fastboot erase dtbo_a
fastboot erase dtbo_b
#+end_src

* Step 3: Flash

With the phone still in the bootloader and the build from step 1 finished:

#+begin_src sh
cd result
./flash-critical.sh
fastboot flash userdata system.img
fastboot reboot
#+end_src

If =fastboot= doesn't see the phone, unplug and replug the cable /after/ the phone shows the bootloader screen. To get back to the bootloader at any time: power the phone off, then hold Volume Up + Power.

* Step 4: First Boot

The first boot takes a little longer while the phone grows its file system to fill the storage. Then GNOME starts; log in as the user =nix= with the password =nixtheplanet=. Change it in a terminal with =passwd=.

Connect to WiFi in GNOME Settings → Wi-Fi. That's it: you're running NixOS.

** SSH over the USB-C cable

The USB-C port works like a laptop's: plug in a keyboard or other USB device and the phone acts as host and powers it; plug it into a charger or PC and it charges. The port is USB 2.0 and has no video output; that's the OnePlus 6 hardware.

One extra a laptop doesn't have: plugged into your PC, the phone also shows up as a network device. No WiFi needed:

#+begin_src sh
ssh nix@172.16.42.1
#+end_src

There's also a serial console, on the PC as =/dev/ttyACM0= (the number can differ): =screen /dev/ttyACM0 115200=.

Copy your SSH key over once, so SSH and copying a kernel over (see below) don't ask for a password every time:

#+begin_src sh
ssh-copy-id nix@172.16.42.1
ssh-copy-id root@172.16.42.1
#+end_src

* Changing the Phone

The easiest is on the phone itself. Clone this repository there once, into =~/phoneputer= (that's where =nh= looks):

#+begin_src sh
git clone https://github.com/mwlaboratories/phoneputer ~/phoneputer
#+end_src

Then edit the configuration there and rebuild, in a terminal on the phone or over SSH:

#+begin_src sh
nh os switch
#+end_src

Nearly everything comes ready-made from the NixOS binary cache. What isn't there is what this configuration changes itself, mainly GNOME Shell with the Stylix colours built in, and the phone builds that itself, in about three minutes. It's faster at it than your PC: a PC builds for the phone's ARM processor through emulation, about three times slower (a GNOME Shell build took 89 s on the phone, 254 s on a 16-thread PC). The one exception is the kernel, which takes hours on the phone and minutes on a PC that cross-compiles it; see [[*Updating the kernel][Updating the kernel]].

Your own wallpaper: replace =hosts/phoneputer/wallpaper.jpg= (or point =stylix.image= in =configuration.nix= at another image; =git add= it, a flake only sees files git knows about), and rebuild. The colours of the whole phone follow the wallpaper. The wallpaper itself and your apps' colours change as soon as the rebuild is done; GNOME's own menus and the login screen after you log out and back in.

To pick up changes to this repository on the phone:

#+begin_src sh
cd ~/phoneputer
git pull
nh os switch
#+end_src

To pick up new hardware fixes from the Mobile NixOS fork and new NixOS packages, update the inputs (on the phone or your PC, then commit and pull), and rebuild on the phone as above. If the update changes the kernel, the rebuild stops at the kernel: build it on your PC first, as below.

#+begin_src sh
nix flake update
#+end_src

** Updating the kernel

The phone doesn't compile its own kernel (that takes hours); your PC cross-compiles it in minutes. Build it there and copy it to the phone, then rebuild on the phone as usual:

#+begin_src sh
nix copy --to ssh://root@172.16.42.1 .#kernel
ssh -t nix@172.16.42.1 'cd ~/phoneputer && git pull && nh os switch'
#+end_src

The kernel also lives in the phone's =boot= partition, which the bootloader starts directly, so flash a new boot image too. Build it on your PC:

#+begin_src sh
nix build .#boot-image -o boot.img
#+end_src

Send the phone to the bootloader and try the new kernel once, without flashing it. The next reboot goes back to the old kernel:

#+begin_src sh
ssh root@172.16.42.1 reboot bootloader
fastboot boot boot.img
#+end_src

If everything works, flash it for good:

#+begin_src sh
ssh root@172.16.42.1 reboot bootloader
fastboot flash boot boot.img
fastboot reboot
#+end_src

* 4G / LTE

Insert a SIM card and reboot. Mobile data appears in GNOME Settings → Mobile Network. To check the modem from a terminal:

#+begin_src sh
mmcli -L
mmcli -m 0
#+end_src

Without a SIM, =mmcli -m 0= reports state =failed= with reason =sim-missing=. That is expected.

The hardware itself is not in this repository:

** The Mobile NixOS fork

Upstream Mobile NixOS still ships the OnePlus 6 kernel at Linux 6.4, and its kernel build doesn't install kernel modules when cross-compiling. The Qualcomm modem stack (QRTR, QMI, RMNET, IPA) is built entirely from modules, so upstream never brings the modem up. The [[https://github.com/mwlaboratories/mobile-nixos][fork]] fixes that and adds the rest of the hardware:

- *Kernel*: Linux 7.4 from the =sdm845-linus= branches of the [[https://codeberg.org/sdm845/linux][sdm845 kernel tree]], with working modules (=isModular=, a matching =modDirVersion=, zstd, an explicit =depmod=), USB-C role switching and OTG power. The GPU, display and video clock controllers are built in; as modules they load too late and the screen stays black.
- *Firmware*: the paths the kernel expects (=qcom/sdm845/OnePlus/enchilada=, =qca/OnePlus/enchilada=) point at the OnePlus firmware package.
- *Bluetooth and WiFi addresses*: no factory addresses reach the mainline kernel, so the phone derives stable ones (Bluetooth from the serial number).
- *Sensors*: =hexagonrpcd= serves the sensor DSP its configuration, and =iio-sensor-proxy= reads the sensors from it.
- *USB-C gadget*: Mobile NixOS normally only sets up USB during early boot. The fork keeps a network interface and a serial console after boot (=mobile.usb.stage-2=).

* Back to Android

To put the stock OnePlus firmware (OxygenOS, the Android the phone ships with) back on the phone, as it came out of the box. This erases everything on the phone again.

⚠️ Not yet tested with this tutorial; the steps follow [[https://www.thecustomdroid.com/oneplus-6-6t-unbrick-guide/][The Custom Droid's unbrick guide]] (2022) and the [[https://wiki.realmofespionage.xyz/android:oneplus_6_enchilada][Realm of Espionage wiki]] (2024). Only use packages for the OnePlus 6 (/enchilada/), never the 6T's.

The usual way is the MSM Download Tool, OnePlus's own service tool for its repair centres. It isn't published by OnePlus, but shared with the firmware packages on XDA (thread 3914109, "OP6 collection unbrick tools"); check the package's checksum before using it. It runs on Windows only and rewrites every partition through the phone's emergency download mode (EDL), so it works whatever is on the phone now:

1. On a Windows PC, install the Qualcomm HS-USB QDLoader 9008 driver.
2. Unpack the OnePlus 6 package (the newest is OxygenOS 10.3.8, =enchilada_22_J.50_210121=) and start =MsmDownloadTool V4.0.exe=.
3. Power the phone off. Hold Volume Up and Volume Down together and plug in the cable (a USB 2.0 port; USB 3 ports cause errors). The screen stays black: that's EDL. Windows' Device Manager shows "Qualcomm HS-USB QDLoader 9008".
4. Click Start. When it's done the phone reboots into OxygenOS. If it stays black, hold Power and Volume Up for 20 to 30 seconds.

According to the guide, the tool also locks the bootloader again. Then update to the latest OxygenOS in Settings → System → System updates, as in [[*Update OxygenOS and remove Google accounts][Step 2]], and the phone is as it came out of the box.

On Linux, the same firmware package can be written with [[https://github.com/bkerler/edl][bkerler/edl]] after decrypting it with [[https://github.com/bkerler/oppo_decrypt][oppo_decrypt]]; the Realm of Espionage wiki has the commands. That route doesn't lock the bootloader again.
